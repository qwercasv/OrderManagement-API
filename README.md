Tech Stack: ASP.NET Core (.NET 8), Entity Framework Core (Code-First), SQL Server, JWT Authentication, 
HTML5 / Tailwind CSS (Frontend).

Arquitectura RESTful con separación estricta mediante DTOs (evitando sobreexposición de entidades y bucles de serialización).

Lógica de negocio server-side para validación estricta de inventario y cálculo seguro de precios.

Seguridad robusta implementando autenticación basada en tokens JWT y protección de endpoints mediante [Authorize].

Módulo de Delivery y Seguimiento integrado al ciclo de vida de las órdenes.
